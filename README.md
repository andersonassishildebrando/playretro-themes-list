# Play Retro — lista de temas

Lista usada pelo baixador de temas do [Play Retro](https://github.com/andersonassishildebrando/playretro)
(menu *Configurações da interface → Baixar temas*). O app clona este repositório e lê `themes.json`.

Cada entrada aponta para o repositório do próprio autor do tema; os temas pertencem aos seus autores
e seguem as licenças de cada repositório.

Para adicionar ou remover um tema, edite `themes.json`. Campos principais: `name`, `reponame`
(nome da pasta local), `url` (repositório git), `author`, `variants`, `colorSchemes`,
`aspectRatios` e `screenshots` (opcional: caminhos de imagens dentro deste repositório).
`latestStableRelease` é o número de release mais recente do app.
